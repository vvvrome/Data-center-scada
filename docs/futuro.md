# Trabajo futuro

## 1. Integración con Wazuh

Integrar los logs del laboratorio con Wazuh para construir una capa de monitorización de seguridad centralizada.

Objetivos:

- centralizar logs;
- crear reglas de detección;
- correlacionar eventos;
- generar alertas;
- visualizar actividad;
- estudiar anomalías.

## 2. Seguridad IT/OT

Ampliar la arquitectura para representar de forma más detallada:

- IT;
- DMZ;
- OT;
- CONTROL;
- SAFETY;
- comunicaciones entre zonas.

## 3. Simulación física

Mejorar progresivamente los modelos físicos y matemáticos.

Líneas previstas:

- modelos térmicos más completos;
- integración numérica;
- simulación Sol-Tierra-Luna;
- problema de tres cuerpos;
- integración Leapfrog;
- puntos de Lagrange;
- secciones de Poincaré;
- análisis de estabilidad.

## 4. Monitorización

Añadir almacenamiento histórico de métricas y representación temporal.

También se puede incorporar:

- dashboards históricos;
- estadísticas;
- detección de anomalías;
- correlación entre métricas.

## 5. Ciberseguridad

Ampliar:

- IDS;
- detección de patrones;
- correlación;
- auditoría;
- escenarios de ataque;
- integración SIEM.

## 6. Infraestructura

Añadir:

- redundancia;
- alta disponibilidad;
- balanceo;
- más dispositivos;
- fallos de hardware;
- almacenamiento avanzado.

## 7. Despliegue

Estudiar despliegues mediante:

- Docker;
- Linux;
- máquinas virtuales;
- redes virtualizadas.

## 8. Base de datos

Evaluar PostgreSQL o MySQL para escenarios de mayor escala.

## 9. Testing

Aumentar la cobertura de pruebas y automatizar pruebas de integración.

## 10. Objetivo a largo plazo

Convertir DataCenter Lab en un laboratorio reproducible para experimentar con seguridad de infraestructuras críticas y estudiar la interacción entre sistemas IT, OT, procesos físicos y mecanismos de monitorización.
