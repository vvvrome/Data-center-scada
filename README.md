# DataCenter Lab

Proyecto de laboratorio para la simulación, monitorización
y gestión de una infraestructura de datacenter y sistemas
críticos.

## Componentes

- API Flask
- Gestión de base de datos
- Monitorización
- Seguridad
- Simulación de planta
- Graph Lab
- Infraestructura de datacenter

## Tecnologías

- Python
- Flask
- NumPy
- Matplotlib
- MySQL
- Linux
- Git
